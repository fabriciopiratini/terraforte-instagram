# Skill: Revisão de Conteúdo — Terra Forte

Esta skill define o checklist de revisão para qualquer conteúdo produzido antes da publicação.

## Checklist de revisão — Instagram

Ao revisar um post de Instagram (legenda + arte), verificar TODOS os itens:

### 1. Alinhamento com a marca
- [ ] O tom está adequado? (autoridade + proximidade)
- [ ] A linguagem é acessível para o público-alvo? (produtor rural / dono de terreno)
- [ ] Não menciona política ou religião?
- [ ] Não usa humor ou piadas?
- [ ] Não cita concorrentes?
- [ ] Não usa gírias?
- [ ] Não promete resultado garantido ou prazo específico?
- [ ] Não menciona serviços que não oferecemos (ITR, CCIR, edificações)?
- [ ] Não expõe dados de clientes (nome, matrícula, CPF/CNPJ, coordenadas, foto que identifique a propriedade)?
- [ ] Cita a marca apenas como "Terra Forte"?
- [ ] Está em uma das linhas editoriais (Informativo / Bastidores / Autoridade & Eventos)?

### 2. Precisão técnica
- [ ] As informações técnicas estão corretas?
- [ ] Os termos legais estão certos? (prazos, leis, obrigatoriedades)
- [ ] O serviço descrito corresponde ao que a Terra Forte realmente faz?

### 3. Qualidade do texto
- [ ] Sem erros de ortografia?
- [ ] Sem erros de gramática?
- [ ] Frases claras e diretas?
- [ ] CTA presente e claro?
- [ ] Hashtags presentes e corretas?
- [ ] Tamanho adequado? (não muito longo, não muito curto)

### 4. Qualidade visual (arte)
- [ ] Cores corretas da marca? (#522800, #FFCB2A, #059734, #FFFFFF, #000000)
- [ ] Logo presente?
- [ ] Texto legível sobre o fundo?
- [ ] Visual limpo e profissional?
- [ ] Formato correto? (1080x1350 para feed, 1080x1920 para stories)
- [ ] Se usa foto, é foto real e adequada?

## Checklist de revisão — Rádio

### 1. Alinhamento com a marca
- [ ] Tom confiante mas não arrogante?
- [ ] Linguagem simples para ouvinte rural?
- [ ] Sem política, humor, gírias, concorrentes?

### 2. Estrutura técnica
- [ ] Tempo adequado? (30s ≈ 75-80 palavras / 15s ≈ 35-40 palavras)
- [ ] "Terra Forte" aparece pelo menos 2 vezes?
- [ ] CTA claro? (o ouvinte sabe o que fazer?)
- [ ] Uma mensagem por spot? (não tentou vender tudo de uma vez?)

### 3. Precisão
- [ ] Informações corretas?
- [ ] Nomes citados estão entre os autorizados no CLAUDE.md (Fabrício Lucas, Milena Lucas, Aloncio Garcia)?
- [ ] Serviço descrito corretamente?

## Como apresentar a revisão

Ao fazer uma revisão, apresentar assim:

```
REVISÃO DE CONTEÚDO — [TIPO: Post Instagram / Spot Rádio / etc.]

✅ APROVADO / ⚠️ PRECISA DE AJUSTES / ❌ REESCREVER

Pontos positivos:
• [o que está bom]

Ajustes necessários:
• [o que precisa mudar, com sugestão de correção]

Versão revisada:
[se houver ajustes, apresentar a versão corrigida completa]
```

## Níveis de gravidade

- **✅ Aprovado** — pronto para publicar, sem ajustes necessários
- **⚠️ Ajustes menores** — pequenas correções de texto, hashtag faltando, ajuste de tom
- **❌ Reescrever** — erro grave: informação incorreta, tom inadequado, serviço errado, violação de regra da marca
